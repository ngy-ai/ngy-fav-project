# 2026-09-21

## 加分类与标签（需求：一个仓库一个分类，可挂多个标签）

新增 `src/taxonomy/` 领域模块 + 「分类与标签」管理页（侧栏第四页）。

**数据形状**（`library.json` 向后兼容，缺字段当空）：

```jsonc
"repos": [{ ..., "category": "开发工具", "tags": ["cli", "待读"] }],
"categories": ["开发工具", "学习"],
"tags": ["cli", "待读"]
```

**改动清单**

- 新增 `taxonomy/model.rs`（名字规则纯函数 + `AddName`/`RenameName` 结果枚举 + `hue_seed`）、
  `taxonomy/chip.rs`（分类色块，色相由名字算，浅/深主题两套明度）、
  `taxonomy/taxonomy_view.rs`（词表管理页：增 / 改名 / 删，删除前说清影响几个仓库）。
- `repos/taxonomy_dialog.rs`：草稿式对话框，分类单选（含「不分类」）、标签多选，两边都能当场新建。
- `library.rs`：`add_name` / `rename_name` / `remove_name` / `repo_count_using` /
  `set_repo_category` / `set_repo_tags` / `uncategorized_count` / `normalize_taxonomy`。
- `list_delegate.rs`：`RepoRow` 带上分类与标签，搜索能命中，新增 `CategoryFilter`
  （全部 / 未分类 / 某个分类），筛选状态住在 delegate 里。
- `repos_view.rs`：详情面板加「分类与标签」块；列表栏加分类筛选条（只列非空分类，
  当前选中的那个始终保留）；分类被删掉时筛选自动退回「全部」。
- `app.rs` 侧栏加 `Page::Taxonomy`（图标 `IconName::Tags`）。
- README 补「分类与标签的几条规矩」一节，JSON 示例与测试数（42 → 71）都同步了。

**验证**

- `cargo test` 71 passed / 1 ignored；`cargo clippy --all-targets` 无警告。
- 真机起进程跑了 36 秒无 panic（默认页就是仓库页，筛选条 + 色块都走过了）；
  `library.json`（21 个仓库、无分类标签的旧格式）启动后 mtime 不变 —— 加载时的
  `normalize_taxonomy` 只改内存，不会偷偷改写文件。
- **界面本身仍然截不到**：试了 windows-mcp 的截图，它只看得到宿主桌面
  （`No windows found`），沙箱里那个窗口不在上面。这条与之前的记录一致。

## 踩到的坑（都记进 MEMORY.md 了）

- `entity.read(cx)` 的结果不能同时再借 `cx` 去写盘 → E0502，改走 `entity.update`。
- `window.open_dialog` 的 builder 是 `Fn`，每帧都调用：草稿状态必须放在实体里。
- `cx.theme()` 借 `&cx`，造 `cx.listener` 之前要把颜色抄成值。
- `cargo fmt` 不能跑：项目本来就不是 rustfmt 干净的（90 处 diff，多数是既有文件），
  只手工对齐自己新写的部分。
